Personal portfolio website for Santhiya P.

## Folder Structure

```text
Santhiya_Portfolio_Final/
├── index.html
├── css/
│   └── style.css
├── js/
```

## Run Locally

Open `index.html` in a browser.

## GitHub Pages

Upload the files and folders to a GitHub repository. Keep `index.html` in the repository root, then enable GitHub Pages from the repository settings.
